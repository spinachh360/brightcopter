These blade-free fan-head navigation assets were prepared from the supplied
Base Black, Jumbohead Brown and Nanohead Silver product photos. They are edited
category artwork, not additional product photographs or specification evidence.
The original catalogue photographs remain intact under `../products/`.

`npm run assets:categories` exports matching transparent 256 × 256 WebPs under
`../products/icons/`, centering each head with consistent padding. These small
files are used on home and catalogue category buttons. Product labels remain
visible, while the images are decorative for assistive technology.
